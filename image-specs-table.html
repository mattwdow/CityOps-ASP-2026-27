Technical Production Standards

Attribute Standard Specification Reason
Image Count 7 to 8 photos per branch Provides complete visual rhythm without cluttering the scrollytelling narrative
Primary File Format WebP (.webp) at 80% to 85% quality Delivers 30% to 40% file size savings compared to JPG at identical visual clarity
Fallback Format Progressive JPG (.jpg) Universal browser and archival fallback
Combined Weight Under 2.5 MB total per branch Ensures immediate first-paint load times on mobile and municipal network connections
Hero Height Limit Capped at 360 px on desktop Keeps the Branch Manager greeting visible without forcing an extra scroll
Colour Profile sRGB Prevents colour shifting across different monitor calibrations and mobile screens
